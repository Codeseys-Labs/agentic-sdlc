*Synthesis of 9 area reports covering agentic-sdlc (target), pi-lab (core + docs/research + skills), pi-agentic-sdlc-skills, pi-lab-doc-skills, three Pi workflow-engine forks (pi-dynamic-fractal-workflows, pi-lab-bounded-workflows, pi-adaptive-thinking), five Pi context/memory extensions, pi-ecosystem-research, and the Bedrock/Mantle provider-integration cluster. Verified against `agentic-sdlc` HEAD `ada5ecd` on `release/offline-observer-rc`, 2026-08-05.*

## 1. State of agentic-sdlc

- **Purpose**: a multi-host "open plugin" (`skills/` in Agent Skills format + thin per-host manifests) that turns Claude Code (and any Agent-Skills-aware host) into a project-scale agentic SDLC orchestrator — Frame→Discover→Research→Plan→Act→Review→Reconcile→Ship, backed by a Git-native Seeds queue and worktree waves.
- **8 skills shipped today**: `agentic-sdlc`, `change-writing`, `cmux-event-bus-messaging`, `codex-research-os`, `model-tier-rightsizing`, `repo-toolchain-gates`, `stacked-prs`, `stacked-prs-gh-cli` (confirmed via `ls skills/`).
- **Doctrine is mature, enforcement is partial**: hard evidence/authorization separation is stated throughout (`docs/progress/2026-07-21-prime-candidate-custody.json`'s `authority_boundaries` block) — gates and receipts are evidence, never authorization to push/merge/deploy.
- **The one fully shipped vertical slice** is `skills/agentic-sdlc/tools/offline-inspect.py` — a deterministic, stdlib-only, zero-subprocess, zero-network *preview* inspector (`create`/`adopt`/`merge`/`refuse`/`skip`), explicitly not an activation authority.
- **Safe PRIME activation is preview-only**: `activation-planner.py`/`activation_planner.py` is a hardened, tested transactional engine (statx/fcntl, single-use grants) but the public CLI reportedly exposes only `plan` — no shipped apply/verify/recover path (per `docs/progress/2026-07-21-product-progress-snapshot.md`).
- **Gateway/proxy routing is "canary proven, not productized"**: CLIProxyAPI/claude-code-proxy mixed-model routing passed a live canary but ships no Workflow overlay, RouteQualification type, or dead-gateway refusal.
- **Seeds integration is read-only**: only `prime`/`ready`/`blocked`/`--version` are admitted; no lawful mutation seam (init/create/update/dep) ships, so the mission/backlog-zero doctrine in `references/*.md` cannot run end-to-end yet.
- **Model routing discipline is unusually strict and already ahead of its own siblings**: every dispatch requires a conductor-supplied exact model ID; `resolved`/`inherited`/`unresolved` are distinct states and unresolved stops before dispatch (a real prior incident — three teammate agents silently downgraded — is recorded in `SESSION-HANDOFF.md`).
- **Self-aware about doc/reality drift**: the repo maintains an explicit capability matrix flagging its own overreach (`commands/sdlc-init.md` describes apply/receipts/deactivation the CLI doesn't support yet; `commands/sdlc-wave.md` still prescribes sibling worktrees instead of managed target-local `.worktrees/`).
- **Actively developed, mid-flight**: `SESSION-HANDOFF.md` (uncommitted) records a live, resumable session with a deterministic 18-issue Seeds roadmap and one ready next issue (`agentic-sdlc-p1`, "Execute Complete PRIME slice"); working tree currently has uncommitted hardening changes on top of `ada5ecd`.

## 2. What pi-lab proved

**Wins (real, measured):**
- A genuine transactional install engine (plan→digest→apply→receipt→reversible-uninstall) with **receipt-vouching** that re-derives reversal authority from the *current* reviewed manifest rather than trusting a receipt's own claims — closed two reproduced forged-receipt exploits.
- **Key-level, not file-level**, settings ownership (4 allowlisted keys in the operator's own `~/.pi/agent/settings.json`, union-merge for lists, multiset-aware reversal) — never clobbers operator edits.
- A real AST-based (vendored Acorn) structural policy gate on its one shipped DFW workflow, forbidding loops/imports/eval/fetch/recursion at the syntax level.
- A rigorous, empirically-probed model route ledger (route-probed-positive/negative per exact provider+lane+wire-format+auth+region+id tuple) rather than trusting vendor docs.
- Extensive competitive-teardown discipline against oh-my-pi (20.9k-star Pi hard fork) with named differentiators and named gaps.

**Failures/honest limits (equally load-bearing):**
- **"pi-lab has never delivered a capability to anybody"** as of its own 2026-08-01 self-assessment; doc-to-code ratio measured at 4.5:1 (17,042 doc lines vs 3,812 src lines).
- Two in-repo TUI packages (`pi-desk`, `pi-statusline`) are explicitly excluded from the release payload — `pi-desk`'s own README states "still spawns nothing."
- Its 22 in-tree `skills/house/*` and doc skills are deliberately kept **off** the install payload and off Pi's load path (ADR-0008), because Pi eagerly indexes every loaded skill's description into every turn's system prompt — a real measured cost, not assumed.
- The direct audit of what carried forward into `pi-agentic-sdlc-skills` (`docs/assessment/20260727/ground/sdlc-delivery-plane.md`) found concrete port breakage: `repo-prime` declared but absent from the live loaded-skill list, `codex-research-os` role-count drift (stale "8/17" claim), hierarchical `AGENTS.md` authored-but-unread by Pi, CLI verbs never actually deleted per their own ADR.

**Which extensions actually delivered additional model support (the literal "more model flexibility" claim):**
- **pi-bedrock-mantle** — real, shipping: registers AWS Bedrock Mantle as two fail-closed Pi providers (OpenAI Responses + Anthropic Messages wire formats), with a genuinely new capability (Bedrock Mantle access) not available to Claude Code out of the box, but paid for with hand-pinned static cost tables and a documented incident (39 agents killed by a stale cached bearer).
- **bedrock-mantle-frontier-bundle** — the most rigorous: fronts an *adopted* Claude Code binary with a patched loopback CLIProxyAPI gateway exposing Sonnet 5 + GPT-5.6 Sol/Terra/Luna + GPT-5.5 through Bedrock Mantle, with a 6-rung route-qualification ladder and HMAC-sealed admission envelope — this is the closest existing artifact to agentic-sdlc's own "mandatory local gateway for RuntimeAssignments" ambition, and it works (`ccodex`/`ccodex-uc` launchers), though native recovery is still `pending_canary`.
- **pi-dynamic-fractal-workflows** — doesn't add model *providers* but adds real routing *mechanism*: per-frame budget/agent ledgers, wind-down reserve, price-primary tier ranking — genuinely new orchestration capability over vanilla Pi.
- **pi-adaptive-thinking** — retired; superseded by Pi's own built-in thinking control, but its agent-facing per-turn effort-adjustment tool remains an unfilled gap even after retirement.
- **pi-lab-bounded-workflows** — no new models; a security proof-of-concept only (correctly wraps `tools:undefined` leak in the upstream workflow tool).
