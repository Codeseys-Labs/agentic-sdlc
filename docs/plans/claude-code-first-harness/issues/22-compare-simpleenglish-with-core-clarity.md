# Compare SimpleEnglish with the core clarity profile

Type: research
Status: resolved
Blocked by: none
Parent: [Find the path to a Claude Code-first Agentic SDLC product](../map.md)

## Question

At an exact current upstream commit, compare every substantive rule, workflow step, reference, and
output-style behavior in `AminBlg/SimpleEnglish` with Agentic SDLC's existing BLUF output style and
countable-clarity reference. Identify exact overlap, unique high-value ideas, contradictions,
selection/context cost, update risk, and licence/NOTICE consequences. Recommend whether
SimpleEnglish should remain an optional companion, supply specifically named ideas re-expressed in
one first-party reference with a donor entry, or have no product role. Copy no foreign prose and
do not treat an MIT grant as evidence that duplication is useful.

Asset: `../research/simpleenglish-content-gap-analysis.md`

## Answer

[The exhaustive content-gap analysis](../research/simpleenglish-content-gap-analysis.md) finds
that the core already owns most SimpleEnglish mechanics and is stronger on evidence preservation,
text classification, and honest dictionary limits. It recommends re-expressing only five ideas in
the existing first-party reference: condition before dependent command; expanded contractions and
explicit referents; direct verbs instead of action nouns; advisory semicolon and Latin-abbreviation
flags; and located violations paired with meaning-preserving rewrite candidates. That adaptation
requires an exact MIT donor/NOTICE entry in the same change. Do not add the upstream skill, output
style, rule-number catalog, vocabulary tables, or installer path to the product surface.
