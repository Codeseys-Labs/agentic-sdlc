## Approved auxiliary design

The approved design at `codeseys-feat-mise-cross-host-installer-design-20260713-035802.md` contributes the following bounded requirements for the change-writing lane:

- One globally distributable, output-only skill supports commit, pull request, squash, and draft-review modes.
- Repository instructions and observed history outrank generic formatting conventions.
- Evidence order is instructions, observed style, selected diff or merge-base footprint, test/gate evidence, issue criteria, then non-derivable user context.
- Missing evidence is omitted or represented by a concrete placeholder; it is never filled by plausible prose.
- The skill does not stage, commit, push, create or edit pull requests, merge, or deploy.
- Model or agent authorship text is absent unless explicitly requested for the current artifact; human co-authorship needs evidence or an explicit instruction.
- Tests cover unsupported claims, missing evidence, templates, merge-base scope, attribution opt-in, and output-only authority.

The final public skill name remains a planned implementation choice; the Seeds title uses `change-writing`.
