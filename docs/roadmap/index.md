# Roadmap archive

This directory is the durable explanation and reference record for the approved recovery-and-expansion roadmap. It is not an operating guide and does not authorize integration, publication, configuration changes, checkout moves, or repository renames.

## Records

- [Approved current plan](approved-plan.md) — exact approved-plan copy.
- [Recovered superseded plan](superseded-plan.md) — best recoverable predecessor with provenance and limitations.
- [Decision register](decision-register.md) — accepted direction and authority boundaries.
- [Recovered intent and audit summary](intent-audit.md) — curated requirements evidence without raw session material.
- [Seeds dependency map](seeds-dependency-map.md) — canonical IDs, states, epics, and direct dependency edges.
- [Implementation baseline and branch receipts](baseline-receipts.md) — source baseline and known candidate receipts.
- [Workflow routing certification](workflow-routing-certification.md) — completed route probes and evidence boundary.
- [Trust incident and Seeds graph provenance](trust-incident-and-seeds-provenance.md) — corrected trust evidence, graph provenance, and receipt classifications.

## Reading order

Read the decision register and Seeds map for current direction. Read either plan only when historical rationale or the full implementation sequence is needed. The canonical machine-readable queue remains [`.seeds/issues.jsonl`](../../.seeds/issues.jsonl).

## Record boundaries

This archive deliberately excludes raw session transcripts, tool dumps, credentials, private configuration, and temporary paths. Historical copies can contain stale factual references; they are not present-tense claims unless corroborated by the baseline receipt or canonical Seeds store.
